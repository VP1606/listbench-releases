# listbench-releases

This repository contains all released versions for the Listbench product.

## Earmarkings
There are two live instances of Listbench available:

1. PROD: X.X.X-prod-X
2. DEV: X.X.X-dev-X

**Note:** DEV instances are only to be used for development purposes - all real production instances that will be deployed to the stakeholder should be PROD-marked.

The UI on DEV instances will clearly depict that you are running on a developer internal instance.
